\## Descripción

Notificar cuando la existencia de un producto llega a un mínimo definido.



\## Análisis

Actualmente Perla y Tania detectan que un producto se agotó hasta que un cliente lo pide, generando ventas perdidas.



\## Solución propuesta

Definir un mínimo de stock por producto y mostrar una alerta visual en el sistema cuando se alcance o esté por debajo de ese mínimo.



\## Fuera de alcance en v1

\- Notificaciones automáticas por correo o WhatsApp



\## Estimación

3 horas



\## Prioridad / Dependencia

Media / RF06
