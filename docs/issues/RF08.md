\## Descripción

Permitir crear y administrar categorías de productos (ej. cajas de regalo, decoración, complementos) para clasificar el catálogo.



\## Análisis

Actualmente no existe una clasificación formal; los productos se mezclan en Excel/libreta sin categorías consistentes, dificultando búsquedas y reportes por tipo de producto.



\## Solución propuesta

Módulo CRUD de categorías (alta, edición, baja lógica), disponible como catálogo para asociarlo a cada producto.



\## Fuera de alcance en v1

\- Subcategorías anidadas (categorías dentro de categorías)

\- Traducción multi-idioma de categorías
