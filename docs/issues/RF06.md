\## Descripción

Consultar el stock actual de un producto, filtrando por nombre o categoría.



\## Análisis

Hoy, saber cuánto queda de un producto implica revisar Excel y libreta al mismo tiempo y sumarlos manualmente, lo cual es lento y propenso a error.



\## Solución propuesta

Vista de consulta que muestre existencias actualizadas en tiempo real, calculadas a partir de entradas (RF04) y salidas (RF05).



\## Fuera de alcance en v1

\- Consulta desde dispositivos móviles

\- Filtros avanzados (rango de fechas, proveedor)



\## Estimación

3 horas



\## Prioridad / Dependencia

Alta / RF04, RF05
